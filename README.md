# Auspify Technologies - Task 5: Online Examination System

A full-stack Online Examination System built as part of the Auspify Technologies Software Development Internship.

## Tech Stack
- **Frontend:** Next.js 14, React, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express.js, TypeScript
- **Database:** MongoDB (Mongoose)

## Features
- User Authentication (Register & Login)
- Dynamic Exam Loading (API Integration)
- Interactive Exam Taking Interface
- Automated Result Calculation & Score Reports

## How to Run

### Backend
```bash
cd backend
npm install
npm run dev
